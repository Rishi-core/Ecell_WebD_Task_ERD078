An elegant, responsive landing page for E-Summit 2027, built with plain HTML, CSS, and vanilla JavaScript.

## Highlights

- Clean single-page event landing experience
- Cursor-reactive panels and trace accents
- Responsive layout for desktop and mobile
- No build step required

## Project Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup and content |
| `style.css` | Visual design and responsive layout |
| `script.js` | Scroll behavior and interactive effects |
| `assets/` | Images and static media |

## Local Use

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- This repository is a static site project.
- All interactions are handled with lightweight client-side JavaScript.
